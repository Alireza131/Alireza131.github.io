# Portfolio Website Starter

A responsive one-page portfolio built with HTML, CSS, and JavaScript.

## Files

- `index.html` — page content and structure
- `css/style.css` — all styling and responsive layout
- `js/script.js` — mobile navigation, scroll animations, contact form behavior
- `assets/images/` — replace the SVG placeholders with your real images
- `assets/resume/` — replace the placeholder PDF with your resume

## Before publishing

1. Replace every instance of `Your Name`.
2. Replace `your.email@example.com` in both `index.html` and `js/script.js`.
3. Add your real GitHub, LinkedIn, Facebook, and project links.
4. Replace the images in `assets/images/`.
5. Replace `assets/resume/resume-placeholder.pdf` with your resume.
6. Update the skills, projects, experience, and about text.
7. Test the website locally by opening `index.html`.

## GitHub Pages

Upload all files and folders to your GitHub Pages repository. The `index.html` file must remain in the repository root.
